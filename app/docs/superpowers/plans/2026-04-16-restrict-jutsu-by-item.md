# Restrict Jutsu by Equipped Bloodline Item Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `requiredBloodlineItemId` field to jutsu so admins can gate combat availability on a specific bloodline-associated item being equipped.

**Architecture:** New nullable DB column on `jutsu` with a Drizzle relation → validator field → thin item router endpoint returning only bloodline items → admin hook wires the dropdown → `checkJutsuBloodlineItem` helper in `train.ts` → called in `initiateBattle` jutsu filter (always applied, same as bloodline check).

**Tech Stack:** MySQL + Drizzle ORM, tRPC, Zod, React Hook Form (via `useJutsuEditForm` hook)
